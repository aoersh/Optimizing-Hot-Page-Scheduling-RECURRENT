# 阶段 2：在线控制器参数敏感性

运行：

```bash
MIB=64 CYCLES=3 INTERVAL_MS=20 ./scripts/run_controller_sweep.sh
python3 analysis/summarize_controller_sweep.py results/migration/controller-sweep-*.jsonl
```

本实验扫描访问差阈值 `{10,20,30}` 和每周期迁移上限 `{128,256,512}`。当前热度仍由软件计数器生成，结果用于确定控制周期和迁移限速的 pilot 范围，不作为论文最终参数标签。

软件热页分成访问差值 15、25、35 三档，因此阈值 10、20、30 应分别产生约
1638、1092、546 个高差值页；迁移页数取候选页数与每周期上限中的较小值。

修正后的 64 MiB、3 周期结果摘要：

| 阈值 | 最大迁移页数 | 总迁移页数 | 平均控制耗时 | 最大控制耗时 | 错误 |
|---:|---:|---:|---:|---:|---:|
| 10 | 128 | 384 | 1.216 ms | 1.234 ms | 0 |
| 10 | 256 | 768 | 1.432 ms | 1.524 ms | 0 |
| 10 | 512 | 1536 | 2.000 ms | 2.071 ms | 0 |
| 20 | 128 | 384 | 1.119 ms | 1.126 ms | 0 |
| 20 | 256 | 768 | 1.324 ms | 1.348 ms | 0 |
| 20 | 512 | 1536 | 1.855 ms | 1.920 ms | 0 |
| 30 | 128 | 384 | 1.100 ms | 1.111 ms | 0 |
| 30 | 256 | 768 | 1.309 ms | 1.349 ms | 0 |
| 30 | 512 | 1536 | 1.806 ms | 1.839 ms | 0 |

首轮扫描曾错误地让所有热页使用同一访问差值，无法观察阈值敏感性；该数据已废弃，
程序现已改为三档差值并重新运行。
