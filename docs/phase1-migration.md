# 阶段 1：热页迁移 pilot

`migration_bench` 按 90:10 或 75:25 将工作集初始分配到 DRAM/CXL，把 CXL
页面作为热页，测量冷缓存随机指针追逐延迟；随后用 `move_pages()` 将热页迁移到对应
DRAM 节点，再次测量并验证驻留。

运行：

```bash
./scripts/run_migration_pilot.sh
```

脚本覆盖两个近端和两个跨插槽 CXL 拓扑，以及 90:10、75:25 两种比例，原始
JSONL 写入 `results/migration/`。

首轮 64 MiB pilot 的结果如下：

| 拓扑 | DRAM:CXL | 迁移页数 | 迁移耗时 | 迁移前延迟 | 迁移后延迟 |
|---|---:|---:|---:|---:|---:|
| socket 0 近端 CXL | 90:10 | 1638 | 3.61 ms | 350 ns | 115 ns |
| socket 0 近端 CXL | 75:25 | 4096 | 8.48 ms | 354 ns | 121 ns |
| socket 1 近端 CXL | 90:10 | 1638 | 3.49 ms | 323 ns | 115 ns |
| socket 1 近端 CXL | 75:25 | 4096 | 8.17 ms | 327 ns | 120 ns |
| socket 0 跨插槽 CXL | 90:10 | 1638 | 4.72 ms | 777 ns | 115 ns |
| socket 0 跨插槽 CXL | 75:25 | 4096 | 11.34 ms | 780 ns | 120 ns |
| socket 1 跨插槽 CXL | 90:10 | 1638 | 4.76 ms | 771 ns | 115 ns |
| socket 1 跨插槽 CXL | 75:25 | 4096 | 10.95 ms | 777 ns | 120 ns |

所有迁移的逐页状态和迁移后驻留复核错误均为 0。该实验用于跑通“混合分配 ->
热页访问 -> 迁移 -> 再测量”的闭环。当前热页选择是固定 CXL 区域，不代表最终 MLP
热度选择器；最终实验需要替换为访问采样驱动的候选页集合。`clflush` 在计时区间外执行，
结果表示冷缓存依赖访问延迟，不应与 MLC 报告的平均延迟直接比较。
