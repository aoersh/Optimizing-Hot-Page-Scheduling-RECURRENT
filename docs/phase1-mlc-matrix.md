# 阶段 1：Intel MLC W21/W23/W27 正式矩阵

## 配置

- Intel MLC v3.13 `--loaded_latency -e -r`；每次输出 19 个注入延迟点；
- 每个流量线程使用两个地址流：Node 0/1 DRAM 与近端 CXL Node 2/3；
- `W21`、`W23`、`W27` 由 MLC per-thread 配置原生定义；
- 90:10 和 75:25 通过地址流比例 `10`、`25` 配置；
- Socket 0 使用延迟核 0、流量核 1–15、内存 Node 0/2；
- Socket 1 使用延迟核 16、流量核 17–31、内存 Node 1/3；
- 每场景工作集 64 MiB/线程，首轮每场景 1 次重复。

运行入口：

```bash
WORKLOADS='W21 W23 W27' CXL_PERCENTS='10 25' REPEATS=1 \
  SCENARIOS='socket0:0:1-15:0:2 socket1:16:17-31:1:3' \
  ./scripts/run_phase1_mlc_matrix.sh /tmp/hotpage-perf-check/mlc-matrix-r1
```
