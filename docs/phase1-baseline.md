# 阶段 1：物理 DRAM/CXL 基线

## 首轮 pilot

运行命令：

```bash
MIB=128 SECONDS_PER_TEST=0.25 REPEATS=3 ./scripts/run_baseline.sh
```

原始 JSONL：`results/baseline/20260821-172010.jsonl`（默认被 `.gitignore` 忽略）。
该轮实验用于验证流程和数量级，不作为最终论文结果。

| 场景 | 顺序读 (MiB/s) | 顺序写 (MiB/s) | 随机指针追逐 (ns) |
|---|---:|---:|---:|
| socket 0 本地 DRAM | 22374 +/- 291 | 13818 +/- 255 | 106.6 +/- 0.0 |
| socket 0 近端 CXL | 11205 +/- 1272 | 6971 +/- 944 | 250.6 +/- 9.8 |
| socket 0 跨插槽 CXL | 5954 +/- 280 | 3479 +/- 174 | 492.8 +/- 6.2 |
| socket 1 本地 DRAM | 22592 +/- 549 | 13820 +/- 452 | 106.1 +/- 0.5 |
| socket 1 近端 CXL | 12118 +/- 883 | 7531 +/- 630 | 229.0 +/- 4.6 |
| socket 1 跨插槽 CXL | 6204 +/- 161 | 3697 +/- 148 | 478.6 +/- 12.9 |

表中为 3 次重复的均值 +/- 样本标准差。每个场景的 32768 个页面均通过
`move_pages()` 验证在请求的内存节点上，placement 错误为 0。

## 当前解释

- 本地 DRAM 的顺序带宽最高，随机访问延迟最低。
- 近端 CXL 的随机延迟约为本地 DRAM 的 2.2--2.4 倍。
- 跨插槽 CXL 的随机延迟约为本地 DRAM 的 4.5--4.7 倍，且带宽进一步下降。
- socket 0 与 socket 1 的方向基本对称，说明当前拓扑映射和绑核生效。

这是自研基准，不是 Intel MLC W21/W23/W27；测试时 CPU governor 保持系统现状
`powersave`，透明大页通过进程内 `MADV_NOHUGEPAGE` 禁用。正式实验需固定更长测量窗口、
增加重复次数，并在获得 MLC 后单独建立论文对照数据。
