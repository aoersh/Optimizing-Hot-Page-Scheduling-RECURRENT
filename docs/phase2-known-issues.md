# 阶段 2：已知问题、影响与处置方案

本文只记录通过环境检查或实际实验确认的问题。pilot 数据用于工程闭环验证，不能在问题解决前标记为论文正式复现结果。

## 1. 真实逐页热度采样已解决，DAMON 仍不可用

**证据**：初始环境的 `kernel.perf_event_paranoid=4` 曾阻止 perf；目前实验期间已临时调整为 0，
PEBS load 采样、数据地址和采样 CPU 均已验证。`/sys/kernel/mm/damon/admin` 仍不存在。

**影响**：阶段 2 已能透明获得统计性的逐页访问样本并生成六维特征。PEBS 不是完整 trace，
双节点受控 pilot 的已判定页面准确率约 72.93%，正式训练必须固定采样窗口并重新标定阈值。

**处置**：阶段 3 使用 `SAMPLE_PERIOD=1000` 作为 pilot 起点，记录页面覆盖率和采样开销；
DAMON 不再作为阶段 2 的前置条件。实验结束后是否恢复 perf sysctl 由管理员决定。

## 2. Intel MLC 已安装，但论文工作负载配置待完成

**证据**：已从 Intel 官方安装 v3.13，并成功运行非 root smoke test。`W21/W23/W27`
仅能配合 `-o` per-thread 配置文件，论文没有披露完整文件内容。

**影响**：MLC 缺失问题已经解除，但在 per-thread 配置和运行矩阵冻结前，自研基准及 smoke test
仍不能等同论文 W21/W23/W27。

**处置**：固定 v3.13；使用 `-e -r` 非 root 模式；下一步生成 W21/W23/W27 的
per-thread 配置，并固定线程、节点、工作集、预热和测量时长。详见 `docs/mlc-installation.md`。

## 3. 在线阈值扫描曾缺少区分度

**证据**：首轮在线扫描把所有软件热页的访问差设置为 35，阈值 10、20、30 得到相同候选集合。

**影响**：首轮数据只能反映 `MAX_MIGRATIONS`，不能反映阈值敏感性。

**处置**：该轮数据已废弃；热页改为差值 15、25、35 三档并完成复跑。后续合成数据在扫描前必须验证特征分布和每个参数是否实际改变控制决策。

## 4. 控制周期计时口径曾不完整

**证据**：初版 `control_seconds` 只覆盖迁移和迁移后查询，没有覆盖迁移前驻留查询、特征计算和候选筛选。

**影响**：旧值低估控制器开销，不能用于判断 `MIGRATION_INTERVAL` 是否可执行。

**处置**：计时起点已移动到整个控制窗口入口。修正后 64 MiB pilot 的完整控制耗时约 1.1--2.1 ms，低于当前 20 ms 周期；正式实验仍需加入真实采样和工作负载并重新测量。

## 5. `move_pages()` 状态参数不可省略

**证据**：迁移探针曾在 `status=NULL` 时返回 `EFAULT`，但后续驻留查询显示页面实际已迁移。

**影响**：仅按系统调用返回值会把成功迁移误报为失败，也无法得到逐页 errno。

**处置**：所有迁移调用均提供状态数组，并以“返回值、逐页状态、迁移后驻留查询”三者共同判定成功。

## 6. 缓存会掩盖 CXL/DRAM 延迟差异

**证据**：小热集重复访问会进入 LLC，无法代表页面所在内存层级。

**影响**：迁移前后结果可能主要测量缓存命中，而不是 CXL 到 DRAM 的变化。

**处置**：迁移 pilot 使用随机指针链，并在计时区间外逐页 `clflush`。该值表示冷缓存依赖访问延迟，仍不能与 MLC 平均延迟直接比较。

## 7. 物理拓扑与论文模拟环境不等价

**证据**：本机为双路、四 NUMA 节点、双真实 CXL；论文为 QEMU 双节点模拟。近端和跨插槽 CXL 的 distance 分别为 14 和 24，实测延迟差异显著。

**影响**：论文的绝对延迟、带宽和最优迁移参数不能直接复用。

**处置**：Node 0/2、Node 1/3 作为论文二节点对照；跨插槽和四节点结果作为增强实验单独报告，参数必须在本机重新扫描。

## 8. 系统策略和测量稳定性尚未完全固化

**证据**：自动 NUMA balancing 开启，CPU governor 为 `powersave`，正式基线目前只有 3 次短时 pilot。

**影响**：内核可能额外迁移页面，频率变化和背景负载会影响重复性；当前 pilot 不满足正式统计要求。

**处置**：正式运行前固定并记录 NUMA balancing、governor、THP、CPU 集合和背景负载；每场景至少 5--10 次、延长测量窗口并报告置信区间。全局策略变更必须由管理员批准并在实验后恢复。
